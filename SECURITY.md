# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's [private vulnerability reporting](https://github.com/SlyOtis/chatnip/security/advisories/new) on this repository. Include what you found, how to reproduce it, and the version you ran (`chatnip version`).

You will get an answer within a week. Fixes are released as soon as they are ready and credited in the release notes unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.

## How Chatnip handles your data

Chatnip stores everything locally and keeps tokens and passwords in the macOS Keychain. The details are in [docs/security.md](docs/security.md).
